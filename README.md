# Neon Muncher 🎮

**Neon Muncher** is a 50-level Pac-Man-style browser game built with **HTML, CSS, JavaScript, Canvas, and Three.js**. It combines classic maze gameplay with a neon arcade-style interface, progressive difficulty, ghost AI, scoring, audio effects, and an interactive 3D career map.

### ✨ Features

* 🎯 50 playable levels with increasing difficulty
* 🗺️ Interactive Three.js career map with locked/unlocked levels
* 👻 Ghosts with different movement personalities and behaviors
* 🟡 Pac-Man-style pellet collection and scoring
* ❤️ Lives, countdowns, collisions, level completion, and progression
* 💾 Local progress and high-score saving
* 🔐 Guest and password-based account support
* ☁️ MongoDB synchronization for registered accounts
* 🎵 Background music and queued game sound effects
* 🌈 Different visual themes across levels
* 📊 Career progression and 50-level high-score system
* 📱 Browser-based gameplay with no frontend framework required

### 🛠️ Technologies

**Frontend:** HTML5, CSS3, JavaScript, Canvas API
**3D Map:** Three.js
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Authentication:** JWT + Google Sign-In
**Storage:** Browser Local Storage + MongoDB

### 🎮 Game Flow

Players begin as a guest or account user, enter the neon arcade interface, select their level from the 3D career map, and progress through 50 increasingly challenging maze levels. Completing levels unlocks new stages while scores and progression are saved automatically.

### 🚀 Running the Project

The frontend can be launched using **VS Code Live Server** or a simple Python HTTP server. The optional Node.js/Express backend provides account authentication and MongoDB progress synchronization.

> **Neon Muncher** was built as a personal game development project to explore browser game development, JavaScript architecture, Canvas rendering, game logic, AI behavior, 3D interfaces, audio systems, authentication, and database integration.
